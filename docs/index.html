CUTLAB / EXACT BINARY ENERGY

A cut.
A complete proof.

Local choices can disagree with the best joint decision. Reduce a supplied binary energy to a network. Follow every flow, every cut and every tied optimum.

Exact rational Python and independent BigInt JavaScript. Established submodular graph cuts, not a learned model or a new algorithm. Six variables. No API. Certificates are mathematical witnesses, not machine-checked formal proofs.

01 / SUPPLY THE ENERGY

Costs can be negative.
Capacities cannot.

Unary rows are [cost0,cost1]. Each pair has i<j and values [00,01,10,11], not little-endian mask order. Rational costs are strings. Source side means label 0.

02 / THE JOINT DECISION

Unary-only ignores every pair term. Strict best single-flip search starts at all zero, takes the lowest strictly improving neighbor, and breaks improvement ties by variable index. Neither is an exact joint optimizer.

03 / RETAIN THE CONSTANTS

Four entries.
One directed edge.

For [A,B,C,D], use A + (C-A)xᵢ + (D-C)xⱼ + w(1-xᵢ)xⱼ, where w=B+C-A-D. The edge i→j charges only [0,1]. A negative w is refused, never clipped.

Sum all constants and linear terms. A positive linear l uses s→i with capacity l. A negative l uses i→t with capacity -l and adds l to the offset. Zero edges do not carry flow.




04 / AUGMENT, INCLUDING BACKWARD
Flow can be undone.
The bound only rises.
Shortest residual paths use exact rational bottlenecks. Reverse arcs cancel previous flow. The last state has no s→t residual path. Select a cut below to recolor the network.
Graph and tables scroll horizontally on small screens. Rose nodes: source side, label 0. Teal nodes: sink side, label 1. Orange edges cross from source to sink. Edge labels are flow / capacity. Moved labels have dotted leaders. Very long rational labels use edge IDs; exact values remain in tooltips and the full edge table. Geometry is illustrative, not an image segmentation result.


05 / EVERY CUT, NOT A CHOSEN WINNER
Energy = offset + cut.
Cut ≥ flow.
For every cut, capacity minus final flow equals its outgoing residual sum. That nonnegative slack is zero exactly for a minimum cut. The original energy is independently enumerated from the supplied tables.


06 / THE WHOLE OPTIMUM FAMILY
A tied optimum
is not a forced label.
A minimum source set contains s, excludes t and has no positive residual arc leaving it. Strongly connected components move together. The condensation edges impose forward-closure constraints, not independent choices for each free variable.




07 / A LOCAL STOP CAN BE WRONG
No improving flip
is not a global proof.
This fully inspected local search is a failure control, not a competitive performance benchmark. The exact cut certificate is independent of its trajectory. Refused non-submodular inputs retain only the tiny exhaustive reference and local control, not a graph-cut result.




08 / BOUNDARIES & PRIOR WORK
A finite witness.
Not a vision benchmark.
One to six binary variables, up to fifteen distinct pair scopes, signed rational costs with bounded numerator and denominator. Binary pairwise submodular terms only. Non-submodular tables are refused under the supplied variable coding; we do not search label flips, use roof duality or claim that every refused energy is impossible to represent after other transformations.
These are supplied energy costs, not learned probabilities, calibrated confidence, causal effects or evidence of real image quality. We retain every tiny assignment to verify the reduction and optimum family. That reference and full family enumeration are exponential. Augmentation counts are not timings or memory measurements; rational bit complexity is not benchmarked.
The graph construction, maxflow/mincut duality, shortest augmenting paths and residual closure are established methods. Python rejects duplicate keys and bounds input to 32KiB UTF-8; browser JSON.parse keeps the last duplicate key and bounds 32,768 characters. Python index tokens must be integers; browser integer-valued tokens such as 1.0 are accepted.
