CUTLAB / AFFINE UNARY RESPONSE

Every interval.
Every boundary tie.

Change a cost, and the best joint decision can change. Compute the entire exact response over a supplied rational interval. Do not mistake one sampled answer for a complete path.

At most six synthetic binary variables. Exhaustive affine-line inequalities plus independent flow/cut witnesses. Established parametric optimization, not a scalable parametric flow algorithm or a learned prediction.

01 / SUPPLY A COST PATH

Base + λ × slope.

Each unary entry becomes base[i][label] + λ × slopes[i][label]. Fixed pair costs do not change. Domain endpoints and all coefficients are rational strings. No clipping or sign restriction on unary slopes. A negative pair slack is refused.

02 / THE COMPLETE LOWER ENVELOPE

A decision is an affine line.

For each assignment m, Eₘ(λ) = interceptₘ + slopeₘ × λ. It is optimal exactly where every inequality Eₘ(λ) ≤ Eₖ(λ) holds. Intersect all these closed half-intervals with the supplied domain. An empty region is never optimal. A singleton region wins only at one point.

Rose: optimum envelope. Teal dashed: selected assignment line. Plot coordinates are approximate; all interval endpoints, energies, ties and inequalities below are exact. The plot scrolls on small screens.



03 / OPEN CELLS ARE NOT THEIR ENDPOINTS
Keep the boundary family.
Every point and each open-cell midpoint is independently solved by exact maxflow/mincut, with the full original-energy, reduction, augmentation, residual and tied-family report retained below. The all-line inequalities certify the whole interval; the midpoint solve alone does not.


04 / WHAT IS NOT PROMISED
Mixed slopes need not nest.
In the default control, the unique open-cell masks are 7, 0, 1 as λ increases through 1/4 and 2. Variable x0 is 1, then 0, then 1. Monotone source-sink parametric-flow guarantees need their assumptions. We do not infer nested labels from an arbitrary signed unary path.
All feasible assignments are enumerated. There are 2ⁿ lines and quadratic all-line inequalities; no large-graph complexity, learned calibration, causal effect, image segmentation or formal verification is claimed. Derived rational arithmetic is exact, while SVG geometry is not. Native JSON rejects duplicate keys and bounds UTF-8 bytes; browser JSON.parse keeps the last duplicate and bounds characters, as in the original inspector.
